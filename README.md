# ENGLISH LEARNING ACADEMY — Learn English Step by Step

أكاديمية تعليمية تفاعلية مستقلة لتعلم اللغة الإنجليزية خطوة بخطوة لطلاب المرحلتين الابتدائية والمتوسطة الناطقين بالعربية (وفق إطار CEFR من `Pre-A1` إلى `B1` مع توسع اختياري نحو `B2`).

An independent, interactive English-learning web academy for Arabic-speaking Primary and Middle School students, structured around CEFR (`Pre-A1` to `B1`, with optional `B2` expansion).

---

## المميزات الرئيسية | Key Features

- **واجهة عربية واضحة + محتوى إنجليزي متدرج (RTL & LTR):** شروحات وتوجيهات بالعربية، مع انغماس لغوي متدرج نحو الإنجليزية في المستويات الأعلى.
- **اختبار تحديد المستوى الشامل (Placement Test):** يقيّم المفردات، القواعد، القراءة، الاستماع، بناء الجملة، الكتابة، والتحدث الاختياري لتحديد نقطة البداية الدقيقة.
- **سبع وحدات تعليمية متكاملة:**
  1. **Vocabulary Builder:** 16 محوراً حياتياً وعلمياً + نظام التكرار المتباعد (SM-2).
  2. **Grammar Academy:** 27 درساً من الأساسيات حتى التراكيب المتقدمة مع الأخطاء الشائعة والاختبارات.
  3. **Reading Academy:** نصوص متدرجة مع دعم صوتي، مفردات مساعدة، وأسئلة فهم متنوعة.
  4. **Listening Academy:** نصوص استماع مجانية عبر نطق المتصفح مع التحكم بالسرعة وتدريبات الكلمة المفقودة.
  5. **Speaking Academy:** تدريب على النطق والتعرف الصوتي مع بديل ذاتي متكامل للمتصفحات غير الداعمة.
  6. **Writing Academy:** تدرج من الكلمات والجمل إلى الفقرات والرسائل والقصص والمقالات مع قائمة تقييم ذاتي محلية.
  7. **Exam Preparation:** 5 نماذج تدريبية أصلية متوافقة مع أهداف `Pre A1 Starters` إلى `B1 Preliminary for Schools`.
- **تطبيق ويب تقدمي (PWA):** قابل للتثبيت على iPad وAndroid وأجهزة سطح المكتب ويعمل دون اتصال بالإنترنت بعد التحميل الأول.

## 1. إعداد المشروع والتشغيل المحلي | Project Setup & Local Development

```bash
npm install
npm run dev
```

سيعمل خادم التطوير على `http://localhost:3000`.

للتحقق من البناء الإنتاجي وفحص الأنواع:

```bash
npm run lint
npm run build
npm run preview
```

---

## 2. النشر المجاني على GitHub Pages | GitHub Pages Deployment

يحتوي المستودع على ملف النشر التلقائي `.github/workflows/deploy.yml`:

1. ادفع الكود إلى فرع `main` على GitHub.
2. من إعدادات المستودع على GitHub افتح **Settings → Pages** واختر **Source: GitHub Actions**.
3. يقوم مسار العمل تلقائياً بتمرير متغير `VITE_BASE_PATH="/<repo-name>/"` أثناء البناء حتى تعمل المسارات والأيقونات والصور وأداة PWA بسلاسة دون كتابة روابط ثابتة.
4. يستخدم التطبيق `HashRouter`؛ لذلك فإن تحديث أي صفحة (Refresh) على GitHub Pages لن يسبب خطأ `404`.

---

## 3. التثبيت كتطبيق (PWA) والعمل دون إنترنت | PWA Installation & Offline Support

- **على متصفح Chrome / Edge / Android:** اضغط على زر **«تثبيت التطبيق»** داخل شريط الأدوات أو من صفحة الملفات.
- **على أجهزة iPad / iPhone (Safari):** اضغط زر **«تثبيت على iPad / iPhone»** لاتباع الخطوات (زر المشاركة ← إضافة إلى الشاشة الرئيسية).
- يتم تخزين جميع الدروس والأصول والصور مسبقاً عبر Service Worker (`vite-plugin-pwa`) لتعمل الأكاديمية بسلاسة عند انقطاع الإنترنت.

---

## 4. التخزين المحلي والنسخ الاحتياطي | Local Data Storage & Backup/Restore

- تُحفظ ملفات الطلاب والتقدم وبيانات التكرار المتباعد محلياً على الجهاز عبر **IndexedDB**، وتُحفظ الإعدادات الخفيفة (مثل الوضع الليلي وسرعة الصوت) في **LocalStorage**.
- لا يتطلب التطبيق بريداً إلكترونياً أو رقم هاتف أو بيانات شخصية.
- **القيود المهمة للإصدار المحلي:**
  - البيانات مرتبطة بالجهاز والمتصفح الحالي فقط.
  - مسح بيانات المتصفح يزيل التقدم المحلي.
  - لا توجد مزامنة تلقائية بين الأجهزة في الإصدار الأول.
- **النسخ الاحتياطي والاستعادة:** من صفحة **«ملفات الطلاب والإعدادات»** يمكنك تنزيل ملف `JSON` للنسخة الاحتياطية واستيراده على جهاز آخر مع التحقق التلقائي من صحة البنية قبل الاستيراد.

## 5. جاهزية الترحيل السحابي مستقبلاً | Future Cloud Migration Architecture

فُصلت طبقة البيانات والخدمات بالكامل عن مكونات الواجهة (`src/services/`):

- `StorageAdapter.ts`: واجهة `IStorageAdapter` المعزولة (حالياً عبر `IndexedDBStorageAdapter` ويمكن استبدالها مستقبلاً بـ Cloud Database Adapter).
- `StudentProgressService.ts`: إدارة الملفات، الدروس، الشارات، والتكرار المتباعد.
- `LessonContentService.ts`: فصل المحتوى التعليمي (`src/data/*`) عن منطق العرض.
- `AssessmentService.ts`: تقييم اختبار تحديد المستوى والاختبارات المهارية.
- `UserSettingsService.ts`: إدارة التفضيلات المحلية.
- `AnalyticsService.ts`: تشخيصات محلية للمطورين خالية من البيانات الشخصية مع نقطة ربط اختيارية مستقبلية (`IAnalyticsProvider`).
- `SyncService.ts`: واجهة `ISyncService` (معطلة حالياً في `LocalOnlySyncService`) جاهزة لتفعيل المزامنة وحسابات المدارس والمعلمين مستقبلاً دون إعادة كتابة وحدات التعلم.
